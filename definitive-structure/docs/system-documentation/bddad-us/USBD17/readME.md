# USBD17 - Average length of the segments in a given line, by track type

### 1.1. User Story Description

- As a planner, I want to know the average length of the segments in a given line, by track type.

### 1.2. Questions & Client Answers

#### Question: 
- "In the dataset provided the attribute NumberTracks takes the values 4 or 2; is this related to double/single track, or is it related to something else?"


#### Client: 
- "Number of tracks means number of tracks, it's not the number of rails. 2 track means you have a double track segment. 4 tracks means you quadruple track segment."
