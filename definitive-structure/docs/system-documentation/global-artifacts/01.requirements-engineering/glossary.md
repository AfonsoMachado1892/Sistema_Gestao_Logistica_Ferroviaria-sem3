# Glossary

**Terms, Expressions, and Acronyms (TEA) must be organized alphabetically.**

| **_TEA_** (EN)                        | **_Description_** (EN)                                                                                                                                                                                           |
|:--------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **2D-TREE (KD-TREE)**                 | A spatial index structure built on (**latitude, longitude**) of railway stations, enabling fast geographic queries (like 'nearest stations' or 'stations in an area') for the ESINF component.                   |
| **AISLE**                             | Path between warehouse bays allowing access for picking/storage operations, part of the Warehouse Management in the ESINF component.                                                                             |
| **ALLOCATION ROW**                    | Record representing the specific quantity of a product (SKU) allocated from a box in a bay to fulfill part of an order line.                                                                                     |
| **BAY**                               | A limited storage space within a warehouse Aisle with a defined capacityBoxes for storing Boxes (ESINF component).                                                                                               |
| **BEST FIT DECREASING (BFD)**         | A **Picking Plan** heuristic where unpicked allocations are sorted by weight (largest to smallest) and placed into the **Trolley** that leaves the smallest remaining unused capacity (**USEI03**).              |
| **BOGIE**                             | Wheel assemblies that support a **Wagon** or **Locomotive**. The number and type influence stability and speed.                                                                                                  |
| **BOX**                               | The basic storage unit for a product (**SKU**) in the warehouse, identified by a unique `boxId` and having quantity, optional `expiryDate` (for **FEFO**), and `receivedAt` timestamp (for **FIFO**).            |
| **BOXCAR**                            | Freight **Wagon** designed to transport general goods that require protection from weather conditions.                                                                                                           |
| **BRIDGE**                            | Engineering structure that supports railway lines over obstacles, not considered in the current project scope.                                                                                                   |
| **BUILDING**                          | A structure located within a **Facility**, classified by a **Building Type** (e.g., **Warehouse** or **Grain Silo**).                                                                                            |
| **BUILDING TYPE**                     | A classification describing the function of a building within a station, such as warehouse, office, or terminal facility.                                                                                        |
| **CAESAR CIPHER**                     | An encryption method used in the **ARQCP** component (**USAC01, USAC02**) to encrypt/decrypt strings composed of alphabet characters.                                                                            |
| **CARGO HANDLING**                    | Process of unloading, storing, and dispatching goods at a **Railway Terminal**, managed by the **ESINF** component (**USEI01-USEI05**) via a **text-based interface** (**USLP02**).                              |
| **CIRCULAR BUFFER**                   | An array used in the **ARQCP** component (**USAC05, USAC06, USAC07**) to store data in a continuous loop using head and tail pointers (ring buffer).                                                             |
| **CIRCULATION LINES**                 | Tracks within a **Railway Terminal** where wagons circulate to reach **Unloading Docks** (part of **Cargo Handling**).                                                                                           |
| **COMPLEX ROUTE**                     | A **Route** that includes multiple **Freights** (**USLP07**).                                                                                                                                                    |
| **CONTAINER**                         | A detachable cargo unit transported on compatible freight cars, such as flatcars.                                                                                                                                |
| **COSTUMER REMORSE**                  | A return reason where products are returned while still in good condition due to a customer’s change of decision.                                                                                                |
| **CROSSING (TRAIN)**                  | The operation where trains pass each other, which must be planned at **Sidings** or **Stations** when on single-track lines (part of **USLP07**).                                                                |
| **CYCLE COUNT**                       | An inventory audit. In the context of **Returns**, it's a reason for **Quarantine** to recheck a mismatch found during an audit.                                                                                 |
| **DAMAGED**                           | A return reason indicating that a product or box is physically compromised **USEI05**.                                                                                                                           |
| **DEPARTURE INSTANT**                 | The recorded time a train leaves an **Endpoint** (station/facility) after a stop, to be recorded as part of **USLP07**.                                                                                          |
| **DIMENSIONS**                        | Physical measurements (length, width, height) of **Rolling Stock**.                                                                                                                                              |
| **DISCARDED**                         | The final state of returned goods that cannot be reused or restocked **USEI05**.                                                                                                                                 |
| **DISPATCH OPERATION**                | An **Inventory replenishment** action (**USEI01**) that consumes **Stock** from the "front" of the **Bay** list, guaranteeing **FEFO/FIFO** behavior.                                                            |
| **ENDPOINT**                          | The start or end station/facility of a **Railway Line** or **Freight**.                                                                                                                                          |
| **ELECTRIFIED LINE**                  | A line segment equipped with electrical infrastructure that allows circulation of electric locomotives.                                                                                                          |
| **EXPIRED**                           | 	A return reason indicating a product's expiry date has passed **USEI05**.                                                                                                                                       |
| **FACILITY**                          | Any physical node in the railway network, such as a freight yard, station, or terminal, which can **host** a **Station**.                                                                                        |
| **FEFO**                              | **First-Expired-First-Out** – Inventory principle for **perishable goods**, ensuring items closest to their expiry date are dispatched first (**USEI01**).                                                       |
| **FIFO**                              | **First-In-First-Out** – Inventory principle for **non-perishable goods**, ensuring items that arrived earliest (`receivedAt`) are dispatched first (**USEI01**).                                                |
| **FIRST FIT (FF)**                    | A **Picking Plan** heuristic where an allocation is placed into the first **Trolley** where it fits, scanned in input order (**USEI03**).                                                                        |
| **FIRST FIT DECREASING (FFD)**        | A **Picking Plan** heuristic where unpicked allocations are sorted by weight (largest to smallest) and placed into the first **Trolley** where they fit (**USEI03**).                                            |
| **FLATCAR**                           | Freight wagon designed to transport containers, vehicles, or machinery.                                                                                                                                          |
| **FREIGHT**                           | A set of **Wagons** that must be transported from an origin to a destination.                                                                                                                                    |
| **FREIGHT MANAGER**                   | A system user responsible for analyzing, designing, and adjusting train timetables and dispatching trains (**USLP07**).                                                                                          |
| **FUEL CAPACITY**                     | The amount of fuel a diesel engine **Locomotive** can hold.                                                                                                                                                      |
| **GAUGE**                             | Distance between the inner sides of the two rails of a track, defining what rolling stock can circulate on a **Line Segment**.                                                                                   |
| **GEOGRAPHICAL AREA (RANGE)**         | A map region defined by **latMin, latMax, lonMin, lonMax** used for querying stations in the **2D-Tree** (**USEI08**).                                                                                           |
| **GTH (GO TO HOME)**                  | A track light command that is ignored for the track number, used to display the synoptic board (**USAC04**).                                                                                                     |
| **GRAIN SILO**                        | A specialized **Building** type within a **Facility** used for the bulk storage of grain.                                                                                                                        |
| **HAVERSINE DISTANCE**                | The distance function (in km) using Earth's radius required for **Proximity Search** (**USEI09**) and **Radius Search** (**USEI10**) in the 2D-Tree.                                                             |
| **HOPPER CAR**                        | Freight wagon designed to transport bulk materials like coal, grains, or minerals.                                                                                                                               |
| **INVENTORY**                         | Collection of all **Boxes** (SKUs) stored and managed in the **Warehouse**.                                                                                                                                      |
| **INTERMODAL TERMINAL**               | A **Facility** allowing transfer of goods (containers) between different transport modes (e.g., train, truck, ship).                                                                                             |
| **ITEM**                              | The product definition, identified by an **SKU**, and containing data like `unitWeight` and `volume`.                                                                                                            |
| **LINE SEGMENT**                      | A portion of a **Railway Line**, having characteristics like `lengthM`, `numberTracks`, and `speedLimitKmH`.                                                                                                     |
| **LOCOMOTIVE**                        | Engine-powered vehicle that pulls freight wagons, having a **Locomotive Model**.                                                                                                                                 |
| **LOCOMOTIVE MODEL**                  | The specific model or configuration of a locomotive, defining power, type, and compatibility.                                                                                                                    |
| **LOCOMOTIVE TYPE**                   | Classification defining the power source: **Diesel** or **Electric**.                                                                                                                                            |
| **LOGISTICS**                         | The management, planning, and execution of transporting **Freight** by train, from origin to destination.                                                                                                        |
| **MAKER**                             | Manufacturer of a piece of rolling stock (e.g., wagon model).                                                                                                                                                    |
| **MAX SPEED**                         | Numeric value representing the maximum operational speed of the **Rolling Stock**.                                                                                                                               |
| **MAXIMUM WEIGHT**                    | The maximum load per meter allowed on a line segment.                                                                                                                                                            |
| **MINERAL OIL CAR**                   | A freight car type designed for transporting liquid hydrocarbons or petrochemicals.                                                                                                                              |
| **ORDER**                             | A customer request for products, identified by `orderId` and having a `dueDate` and `priority`.                                                                                                                  |
| **ORDER LINE**                        | An individual item and quantity requested within a customer **Order**.                                                                                                                                           |
| **OWNER**                             | An entity responsible for a **Railway Line** and its maintenance (e.g., **IP**).                                                                                                                                 |
| **PARKING LINES**                     | **Sidings** within a **Terminal** where wagons wait temporarily (part of **Cargo Handling**).                                                                                                                    |
| **PARTIAL ALLOCATION**                | Occurs in **USEI03** when an **Order Line** is split because the total quantity cannot fit in one **Trolley**, or in **USEI02** (partial mode) when not all of the requested quantity is allocated.              |
| **PARTIAL ELIGIBILITY**               | An **Allocation** mode where an **Order Line** is marked **PARTIAL** if allocated quantity is $>0$ and $<$ requested quantity (**USEI02**).                                                                      |
| **PATH**                              | Ordered list of stations through which the train must pass (not necessarily stopping) to travel from endpoint A to endpoint B                                                                                    |
| **PAYLOAD**                           | Maximum weight or volume of goods that a **Wagon** can carry.                                                                                                                                                    |
| **PERISHABLE PRODUCT**                | A product with a limited shelf life that must be handled using FEFO rules.                                                                                                                                       |
| **PICKER**                            | A warehouse worker responsible for collecting products (**Boxes**) from **Bays** to fulfill **Picking Plans** (**USEI04**).                                                                                      |
| **PICKING PLAN**                      | A list of **Allocations** (order, SKU, bay, etc.) grouped into a capacity-bounded **Trolley** based on a packing heuristic (**USEI03**).                                                                         |
| **PICK TASK**                         | An item in a **Pick Batch** representing the action of picking a specific quantity from a bay location.                                                                                                          |
| **PLANNER**                           | A user responsible for designing train routes and allocating resources such as rolling stock.                                                                                                                    |
| **POWER**                             | The energy output of a locomotive, a key factor in calculating travel speed.                                                                                                                                     |
| **PRESSURE CAR**                      | A tank car used to transport pressurized gases.                                                                                                                                                                  |
| **PRODUCT**                           | An item stored and managed within the warehouse system.                                                                                                                                                          |
| **PRODUCT OWNER**                     | Person responsible for defining user stories and ensuring project alignment with goals.                                                                                                                          |
| **QUALITY OPERATOR**                  | A user responsible for managing returned goods, inspecting items in **Quarantine**, and deciding whether to restock or discard them (**USEI05**).                                                                |
| **QUARANTINE**                        | A temporary holding state for **Returned Products**. Items are inspected in **LIFO** order (latest first) before being restocked or discarded (**USEI05**).                                                      |
| **RAILWAY NETWORK**                   | The interconnected structure of all rail lines and stations.                                                                                                                                                     |
| **RAILWAY INFRASTRUCTURE**            | Physical components of the railway network: tracks, stations, terminals, etc..                                                                                                                                   |
| **RAILWAY LINE**                      | A set of connected **Track Segments** forming a route between two **Endpoints**.                                                                                                                                 |
| **RAILWAY TERMINAL**                  | A complex logistics node where **Freight Wagons** arrive to be unloaded, stored in **Warehouses**, and dispatched (part of **Cargo Handling**).                                                                  |
| **RB (RED BLINKING)**                 | A **Track Light** state indicating the track is **inoperative** (**ARQCP**).                                                                                                                                     |
| **RE (RED)**                          | A **Track Light** state indicating the track is **busy** (**ARQCP**).                                                                                                                                            |
| **RECEIVED AT**                       | The ISO timestamp of when a **Box** was received in the warehouse, used for **FIFO** sorting.                                                                                                                    |
| **REFRIGERATED CAR**                  | Freight **Wagon** with cooling systems to transport perishable goods.                                                                                                                                            |
| **RELOCATION**                        | An operation in **USEI01** to update a **Box**'s storage location (warehouse/aisle/bay) without re-sorting the new bay, except for insertion into the new bay's FEFO position.                                   |
| **RESTOCKED**                         | The state of returned goods deemed suitable to be reintegrated into inventory.                                                                                                                                   |
| **RETURN**                            | A product sent back to the warehouse, which must be placed in **Quarantine** for inspection (**USEI05**).                                                                                                        |
| **ROLLING STOCK**                     | All vehicles operating on railways, including **Locomotives** and **Wagons**.                                                                                                                                    |
| **ROUTE**                             | The ordered list of stations through which a train must pass to travel from an origin to a destination.                                                                                                          |
| **ROUTE SEGMENT**                     | An ordered part of a **Route** that references a **Line Segment**.                                                                                                                                               |
| **SCHEDULER**                         | A system used by the **Freight Manager** to dispatch trains, calculate estimated passage times, and plan necessary train crossings (**USLP07**).                                                                 |
| **SERVICE YEAR**                      | The year a piece of **Rolling Stock** (**Locomotive** or **Wagon**) entered into service.                                                                                                                        |
| **SIDING**                            | Secondary track allowing trains to pass or park on single-track lines (part of **Railway Infrastructure**).                                                                                                      |
| **SIMPLE ROUTE**                      | A **Route** that consists of a single **Freight**.                                                                                                                                                               |
| **SKU**                               | **Stock Keeping Unit** – A unique identifier for a product in inventory (**Item**).                                                                                                                              |
| **STATION**                           | A node of the railway network for loading/unloading, train crossing, or assembly, which can **host Facilities**.                                                                                                 |
| **STATION MASTER**                    | User for coordinating station operations, including arrivals and departures.                                                                                                                                     |
| **STATION STORAGE MANAGER**           | User responsible for managing warehouse storage and cargo at a station (Also: Terminal Operator, Warehouse Manager).                                                                                             |
| **STOCK**                             | The total amount of goods (**Boxes**) stored in the **Warehouse**.                                                                                                                                               |
| **SYNOPTIC BOARD**                    | A board present in each station, displayed via the **Board** component, which presents the state of tracks, temperature, and humidity.                                                                           |
| **TANK CAR**                          | Freight **Wagon** designed to carry liquids or gases, such as fuel or chemicals.                                                                                                                                 |
| **TERMINAL OPERATOR**                 | A user of the **Cargo Handling** functionality, managing unloading operations (**USEI01**). (Also: Station Storage Manager).                                                                                     |
| **TIME ZONE**                         | The regional time reference used by a station.                                                                                                                                                                   |
| **TIME ZONE GROUP**                   | A classification for railway stations based on their time zone (e.g., 'CET', 'WET/GMT'), used for indexing in **USEI06**.                                                                                        |
| **TRACK LIGHTS (COMMANDS)**           | A set of commands/states for track signaling: **GE** (Green, track free), **RE** (Red, track busy), **YE** (Yellow, free but assigned), **RB** (Red-blinking, track inoperative), **GTH** (Go To Home/Synoptic). |
| **TRACTION**                          | The force exerted by a **Locomotive** that pulls a train.                                                                                                                                                        |
| **TRAIN DISPATCHER**                  | Operator responsible for scheduling and managing train movements. (Also: Traffic Dispatcher).                                                                                                                    |
| **TRAIN DRIVER**                      | Professional responsible for operating trains, following schedules, and ensuring safe movement. (Also: Locomotive Pilot/Engineer).                                                                               |
| **TROLLEY**                           | Wheeled cart with a fixed weight capacity (in kg), used by **Pickers** to collect and transport boxes during the picking process (**USEI03**).                                                                   |
| **TUNNEL**                            | A railway infrastructure element enabling lines to pass through obstacles.                                                                                                                                       |
| **UNLOADING DOCKS**                   | Access points to **Warehouses**, where goods are unloaded from wagons for storage (part of **Cargo Handling**).                                                                                                  |
| **UNDISPATCHABLE**                    | An **Order Line** status in **USEI02** indicating that 0 quantity could be allocated.                                                                                                                            |
| **WAGON / FREIGHT CAR**               | Railway vehicle designed to transport goods, having a **Wagon Model** and belonging to an **Operator**.                                                                                                          |
| **WAGON MODEL**                       | A specific design or version of a freight wagon, defining its characteristics (payload, type, etc.).                                                                                                             |
| **WAREHOUSE (BUILDING)**              | A **Building** type within a **Facility** used for the general storage of goods, organized into **Aisles** and **Bays**.                                                                                         |
| **WAREHOUSE MANAGEMENT SYSTEM (WMS)** | The software system (**ESINF** component) controlling inventory and **Cargo Handling** operations.                                                                                                               |
| **YE (YELLOW)**                       | A **Track Light** state indicating the track is **free but assigned** to an arriving train (**ARQCP**).                                                                                                          |
| **YARD**                              | Area where trains are assembled, loaded, or unloaded.                                                                                                                                                            |
